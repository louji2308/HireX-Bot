## 1. Executive Mandate & Strict Priority Governance Model

As Head of Product and Engineering for **First Mile**, the core architectural mandate is uncompromising: **we have 26 days until submission (November 15, 2026) and 46 days until final evaluation (December 5, 2026) to ship an eight-module, multi-agent production system with live student impact telemetry for under $2.00 total out-of-pocket cost.**

Engineering teams lose hackathons when they waste two weeks building plumbing that a third-party service already solves, or when they face choice paralysis across multiple competing tools. Therefore, this specification enforces two ironclad rules:
1. **Single-Winner Tool Selection (Zero Ambiguity):** No architectural layer in this document presents "Option A or Option B." Every layer has been interrogated through multi-perspective engineering, product, security, and cost questions to crown **one definitive tool**.
2. **"RevenueCat-Style" Complexity Offloading:** Just as mobile teams integrate RevenueCat to offload receipt validation, subscription state machines, and webhook edge cases to a managed third party, First Mile offloads its ten hardest infrastructure bottlenecks (AST parsing, sandboxed code execution, multi-board scraping, durable agent retries, OAuth token vaults, PDF layout extraction, and cryptographic audit trails) to free or permanent-free-tier third-party primitives. Any third-party service whose free trial expires before **December 6, 2026** is strictly disqualified and excluded from the core build.

## 3. Product & Engineering Validation Matrix (How Each Single Tool Was Chosen)

Before locking in the technology stack, every architectural subsystem was subjected to five mandatory validation questions from the perspectives of **Product Velocity**, **Systems Reliability**, **Cost/Runway (through December 5, 2026)**, **Bharat Accessibility**, and **Hackathon Judging Impact**.

### Validation 1: Core Multi-Agent IDE, LLM Routing, Memory & Institutional Governance
* **Questions Asked:**
  1. *Cost & Token Runway:* How do we run 8 specialized agents across 25+ pilot students and 50+ mock interviews without paying for OpenAI/Anthropic API keys?
  2. *Judging Alignment:* Which platform directly unlocks the **Best Use of AgentFoundry Agents** sponsor award while satisfying the mandatory hackathon rule to build inside AgentFoundry?
  3. *Offline Rural Constraint:* How does a Tier-3 college student with unstable broadband run coding drills without burning cloud tokens?
  4. *Institutional Scale:* How can a non-technical College Placement Officer (TPO) customize employer rubrics and monitor 100 students without us building a separate B2B admin portal from scratch?
* **Alternatives Evaluated & Rejected:**
  * *LangGraph Cloud / CrewAI Enterprise:* Rejected. Paid commercial tiers or credit-card-gated trials; building outside AgentFoundry forfeits sponsor prize eligibility and wastes the 1M free token grant.
  * *Raw OpenAI / Anthropic Direct APIs:* Rejected. Requires upfront paid API credits ($20+) when AgentFoundry already provides 1,000,000 free Smart-Code tokens routing to Claude Haiku 4.5 and GPT-5 Codex.
* **Single Authoritative Decision:** **[AgentFoundry.me](https://www.google.com/search?q=https%3A%2F%2Fagentfoundry.me%2F) (`SMART-Code` Dual-Lab Router + `memory.jsonl` + `Local Mode` Ollama + `Business Mode`)** — **Priority 0**.
  * *Timing Execution Note:* Core AgentFoundry features and the 1M Smart-Code tokens (1,000 credits/month for 3 months) are 100% free through December 5, 2026. For `Business Mode` (which has a 7-day free trial), we develop the TPO integration against local config schemas during Days 1–22 and activate the live 7-day `Business Mode` trial on **November 29, 2026** so it is fully active during the **December 5, 2026** final evaluation window (plus recorded in the November 15 demo video).

### Validation 2: Employer-Trusted Hiring Signal & AI Assurance Certification (Module 6)
* **Questions Asked:**
  1. *Recruiter Trust:* Why would an Indian startup CTO or GCC hiring manager trust an AI-generated readiness score from a Tier-3 fresher?
  2. *Regulatory & Bias Rigor:* How do we prove our evaluation agent does not hallucinate grades, suffer from prompt injection (`<untrusted-data>`), or penalize regional accents/non-elite college names?
  3. *Sponsor Synergy:* Which sponsor provides a live cryptographic verification endpoint specifically designed for Fair Hiring AI Compliance?
* **Alternatives Evaluated & Rejected:**
  * *Custom JWT / Self-Signed Badges:* Rejected. Self-signed badges carry zero third-party assurance and require building custom verification infrastructure.
  * *Polygon / Ethereum Blockchain Attestations:* Rejected. Adds gas fees, wallet friction for recruiters, and unnecessary Web3 complexity.
* **Single Authoritative Decision:** **[TrustModel.ai](https://www.google.com/search?q=https%3A%2F%2Ftrustmodel.ai%2F) (`AgentCert DV` + Free $500 1-Agent Fair Hiring Eval + 1-Year Free OTel Trace Retention)** paired with **[AgentFoundry Live Agent Replay](https://www.google.com/search?q=https%3A%2F%2Fagentfoundry.me%2F)** — **Priority 0**.

### Validation 3: Database, Authentication, OAuth Token Vault & File Storage (All Modules)
* **Questions Asked:**
  1. *Schema Rigor:* Can the database enforce strict foreign-key integrity across our 8 relational tables (`candidate_profiles` through `employment_pipeline_events`) and preserve immutable historical rows?
  2. *OAuth Complexity:* Candidates must link GitHub (for Module 2/3 repo audits) and Google/Gmail (for Module 7 outreach and inbox tracking). Can our auth provider handle OAuth login AND hand us the `provider_token` without a separate OAuth proxy server?
  3. *DPDP Rules 2025 Compliance:* Can we enforce row-level isolation and 1-click cascading data erasure out of the box?
  4. *Free Tier Survival:* Will the free tier stay active through December 5, 2026 without credit card charges?
* **Alternatives Evaluated & Rejected:**
  * *Firebase / Firestore:* Rejected. Document/NoSQL data modeling is poorly suited for our 8-table relational analytics schema and longitudinal SQL aggregations ($\Delta \text{Score} = \text{Score}_{\text{latest}} - \text{Score}_{\text{baseline}}$).
  * *AWS RDS + Auth0 + AWS S3:* Rejected. High configuration overhead across three separate services; AWS RDS free tier requires credit-card verification and VPC plumbing.
  * *Clerk + Neon:* Rejected. Splitting Auth and Postgres across two services forces webhook synchronization between user tables; Supabase gives us Postgres + Auth + OAuth tokens + Resume Blob Storage in one unified SDK.
* **Single Authoritative Decision:** **[Supabase](https://www.google.com/search?q=https%3A%2F%2Fsupabase.com%2F) (PostgreSQL 16 + Supabase Auth with GitHub/Google OAuth + Supabase Storage)** — **Priority 2 (Permanent Free Tier)**.

### Validation 4: Durable Multi-Agent Workflow Orchestration & Parallel Execution (Module 4 & Global State Machine)
* **Questions Asked:**
  1. *State Machine Fidelity:* Every agent task requires explicit states (`planned`, `running`, `awaiting_approval`, `completed`, `failed`, `requires_user_input`). How do we pause an agent workflow while waiting 12 hours for a student to click "Approve Application" and resume seamlessly?
  2. *Parallelism:* Immediately after onboarding, Workflows A (Discovery), B (Application Prep), and C (Training) must execute concurrently without blocking the UI HTTP request.
  3. *Zero Infrastructure:* How do we avoid deploying and paying for a dedicated Redis instance and background worker VMs?
* **Alternatives Evaluated & Rejected:**
  * *BullMQ + Upstash Redis:* Rejected. Requires managing worker processes, custom state serialization, and manual human-approval pause logic.
  * *Temporal Cloud:* Rejected. No permanent free tier without expiring credits; high boilerplate complexity.
  * *Trigger.dev Cloud:* Rejected. Lower free credit threshold and requires separate container execution environment compared to serverless step functions.
* **Single Authoritative Decision:** **[Inngest](https://www.google.com/search?q=https%3A%2F%2Fwww.inngest.com%2F) (Event-Driven Durable Step Functions & `step.waitForEvent`)** — **Priority 2 (Permanent Free Tier: 50,000+ runs/month)**.

### Validation 5: Sandboxed Multi-Language Code Execution for Interviews & QC Pipeline (Module 5)
* **Questions Asked:**
  1. *7-Stage QC Pipeline:* Stage 5 of our QC pipeline requires executing the AI's reference solution against generated edge-case tests *before* a coding question is ever shown to a student.
  2. *Polyglot Support:* Indian engineering students code in Python, Java, C++, and JavaScript. Browser-only WASM (`Pyodide`) cannot run Java or C++.
  3. *Zero Server Cost:* How do we execute Python, Java, C++, and JS safely in isolated sandboxes at $0.00 cost?
* **Alternatives Evaluated & Rejected:**
  * *Judge0 Cloud (RapidAPI):* Rejected. The free tier on RapidAPI has strict daily request caps (often 50 req/day) that will bottleneck a 25-student cohort running multiple test cases per session.
  * *E2B Sandboxes:* Rejected. Usage-billed credit model risks exhaustion before December 5 if students run heavy loops.
  * *Pyodide (Browser-Only):* Rejected as primary engine because Tier-2/3 college students frequently interview in Java and C++.
* **Single Authoritative Decision:** **[Piston Execution Engine](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fengineer-man%2Fpiston) (Public `emkc.org/api/v2/piston` API + Self-Hosted Docker Container inside AgentFoundry VM)** paired with **[@monaco-editor/react](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fsuren-atoyan%2Fmonaco-react)** on the frontend — **Priority 1 (100% Free Open-Source MIT)**.

### Validation 6: Resume & Document Intelligence (Module 1 Intake & Module 7 Tailoring)
* **Questions Asked:**
  1. *Extraction Accuracy:* Students upload multi-column Canva/LaTeX/Word PDFs. Standard `pdf-parse` scrambles columns. What extracts clean Markdown hierarchies for free?
  2. *Truthful ATS Generation:* When tailoring a resume for a State 1 or State 2 job, how do we generate a downloadable, 100% ATS-parseable PDF without paying for an external PDF API or crashing our backend with Puppeteer?
* **Alternatives Evaluated & Rejected:**
  * *LlamaParse Cloud:* Rejected. Free tier is capped at 1,000 pages/day with cloud API key dependency when an open-source local model handles 2-page resumes in 0.8 seconds for free.
  * *Puppeteer / Headless Chrome PDF Generation:* Rejected. Heavy 400MB container footprint and slow cold starts on serverless deployments.
* **Single Authoritative Decision:** **[IBM Docling](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FDS4SD%2Fdocling)** for intake parsing + **[@react-pdf/renderer](https://www.google.com/search?q=https%3A%2F%2Freact-pdf.org%2F)** for ATS-clean PDF generation — **Priority 1 (100% Free Open-Source MIT)**.

### Validation 7: GitHub Repository AST Auditing & Issue Localization (Modules 2 & 3)
* **Questions Asked:**
  1. *Context Compression:* How does the Portfolio Auditor inspect a student's entire GitHub repository (or a 20,000-line Code for India NGO repo for Module 3 localization) without blowing through our 1,000,000 AgentFoundry Smart-Code tokens?
  2. *Verification:* How do we verify whether a repository actually contains unit tests, CI/CD workflows (`.github/workflows`), a `Dockerfile`, and clean commit history?
* **Alternatives Evaluated & Rejected:**
  * *Raw GitHub REST API File-by-File Fetching:* Rejected. Consumes dozens of API calls per repo and pulls noisy lockfiles (`package-lock.json`) into the LLM prompt.
  * *SonarQube Enterprise / CodeClimate:* Rejected. Heavy external setup and paid tiers for advanced branch analysis.
* **Single Authoritative Decision:** **[Repomix](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fyamadashy%2Frepomix) (`--compress` Tree-sitter AST mode)** + **[Octokit (@octokit/rest)](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Foctokit%2Frest.js)** — **Priority 1 (100% Free Open-Source MIT)**. Repomix uses Tree-sitter under the hood to extract function signatures and structural AST outlines while stripping lockfiles, reducing LLM token consumption by ~70%.

### Validation 8: Multi-Channel Indian Job Discovery & Company Research (Modules 4 & 5)
* **Questions Asked:**
  1. *Bharat Fresher Coverage:* Where do real Indian freshers find off-campus roles? Naukri, Indeed India, LinkedIn, Unstop, Internshala, AICTE Internship Portal, NCS, and direct Greenhouse/Lever career boards.
  2. *Legal & Anti-Bot Safety:* How do we ingest listings reliably without violating LinkedIn User Agreement Section 8.2 (no logged-in bot scraping) or paying for $49/month proxy APIs?
* **Alternatives Evaluated & Rejected:**
  * *SerpApi / BrightData / Apify Paid Actors:* Rejected. Trial credits expire or cost >$2.00 for continuous polling across 46 days.
  * *Logged-In LinkedIn Automation Bots (Phantombuster/Playwright Cookie Bots):* Strictly rejected. Violates LinkedIn ToS and risks banning student accounts.
* **Single Authoritative Decision:** **[JobSpy (python-jobspy)](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fspeedyapply%2FJobSpy)** (for concurrent Naukri, Indeed India, Glassdoor, Google Jobs, and public unauthenticated LinkedIn discovery) + **[Jina Reader API (r.jina.ai)](https://www.google.com/search?q=https%3A%2F%2Fjina.ai%2Freader%2F)** (for reading Unstop, AICTE, NCS, and official Amazon/Microsoft interview prep pages into clean Markdown) + **Public Greenhouse/Lever/Ashby JSON Endpoints** — **Priority 1 & Priority 2 ($0.00)**.

### Validation 9: Bilingual Socratic Coaching & Regional Language Bridge (Module 5)
* **Questions Asked:**
  1. *Inclusion:* How do we let a student in Madurai or Bhopal reason through Dynamic Programming in Tamil or Hindi (voice or text) and practice crisp English technical delivery without paying for OpenAI Realtime Audio ($0.06–$0.24/minute)?
* **Alternatives Evaluated & Rejected:**
  * *ElevenLabs / OpenAI Realtime Voice API:* Rejected. Expensive per-minute billing that would exceed $2.00 after just 10 mock interviews.
  * *Browser-Only Web Speech API:* Rejected as sole solution because regional Indian language accuracy varies wildly across browsers and devices.
* **Single Authoritative Decision:** **[Digital India BHASHINI ULCA API](https://www.google.com/search?q=https%3A%2F%2Fbhashini.gov.in%2F)** (Government of India's free ASR + NMT + TTS pipeline for 22 Indian languages) paired with **AgentFoundry's `Claude Haiku 4.5`** Socratic prompt router — **Priority 1 (100% Free Public Infrastructure)**.

### Validation 10: Warm Proof-of-Work Email Outreach & Compliant Portal Execution (Module 7)
* **Questions Asked:**
  1. *Deliverability & Identity:* When sending a Warm Proof-of-Work outreach email with a micro-deliverable and Skill Passport link to a startup founder, should it come from a generic `no-reply@` domain or the candidate's own Gmail address?
  2. *Portal Execution:* How do we pre-fill supported ATS forms and pause cleanly for human review when a site requires CAPTCHA or legal declarations?
* **Alternatives Evaluated & Rejected:**
  * *SendGrid / Mailgun:* Rejected. Sends from a shared marketing IP rather than the student's personal email, hurting recruiter reply rates.
  * *Resend:* Kept only for system notifications if needed, but for recruiter outreach, the candidate's own OAuth-authorized Gmail account is superior and 100% free.
* **Single Authoritative Decision:** **[Gmail REST API](https://www.google.com/search?q=https%3A%2F%2Fdevelopers.google.com%2Fgmail%2Fapi)** (via user-consented `gmail.compose` / `gmail.send` / `gmail.readonly` OAuth scopes for job-thread tracking) + **[Playwright](https://www.google.com/search?q=https%3A%2F%2Fplaywright.dev%2F) inside AgentFoundry's Browser-as-Agent-Tool** (for Level 2 pre-filling and Level 3 approved submission on Greenhouse/Lever portals) — **Priority 1 (100% Free)**.

### Validation 11: Frontend Application, 6-Panel Learning Analytics Dashboard & Cloud Hosting (Module 8)
* **Questions Asked:**
  1. *Dashboard Clarity:* Module 8 requires 6 specific learning-analytics visualizations (4 Metric Cards, Filtered $\Delta \text{Score}$ Line Chart, Horizontal Criterion Bar Chart, Session-by-Topic Heatmap, Dynamic Company Stage Tracker Bars, and Sortable History & Replay Ledger). Which UI stack builds this fastest with zero license cost?
  2. *Cloud Deployment:* Which platform deploys our full-stack web application in one click for free through December 5, 2026?
* **Alternatives Evaluated & Rejected:**
  * *Streamlit / Gradio:* Rejected. Looks like a toy prototype rather than a national-scale civic-tech platform; cannot cleanly render custom interactive Session-by-Topic heatmaps, Monaco code editors, and embedded JSONL replay scrubbers.
  * *Chart.js / D3.js from scratch:* Rejected. Too much low-level SVG boilerplate for a 26-day sprint.
