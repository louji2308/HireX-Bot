## 1. Executive Overview of the Code for a Billion Hackathon 2026

The [Code for a Billion — Bharat Agentic-AI Hackathon 2026](https://www.google.com/search?q=https%3A%2F%2Fcodeforindia.org%2Fhackathon) is a 90-day, fully virtual national impact competition running from **August 15, 2026** (India's 80th Independence Day) through **November 15, 2026**, with final evaluation and winner announcements on **December 5, 2026** at an awards ceremony in New Delhi ([ANI News Release](https://www.google.com/search?q=https%3A%2F%2Fwww.aninews.in%2Fnews%2Fbusiness%2Fcode-for-india-announces-code-for-a-billion-a-90-day-agentic-ai-impact-hackathon-to-launch-on-indias-80th-independence-day20260814204042%2F); [AgentFoundry Hackathon Hub](https://www.google.com/search?q=https%3A%2F%2Fkarlmehta.github.io%2Fcode-for-a-billion%2F)). Launched on the same day as the Prime Minister's Red Fort commitment to train **1 crore (10 million) young citizens in AI skills**, the hackathon challenges builders worldwide to turn India's AI potential into **deployed, open-source digital public goods** that demonstrably improve real lives.

Unlike weekend toy-prototype hackathons with pre-written problem statements, **Code for a Billion** provides **no pre-set project briefs** ([Code for India Hackathon](https://www.google.com/search?q=https%3A%2F%2Fcodeforindia.org%2Fhackathon)). Winning teams must independently define a massive civic or economic bottleneck within one of ten national tracks, prove the quantitative scale and severity of that problem, engineer an open-source multi-agent solution inside the official [AgentFoundry.me](https://www.google.com/search?q=https%3A%2F%2Fagentfoundry.me%2F) IDE (backed by **1,000,000 free Smart-Code tokens**), deploy the production system to live cloud infrastructure before **November 15, 2026**, and present **verifiable field deployment data** rather than theoretical intentions.

## 5. GitHub Repository, Open-Source Licensing & Submission Requirements for Winners

The hackathon's official rules establish specific requirements around **GitHub repositories, open-source licensing, contributor attribution, and submission mechanics** ([Code for India Hackathon](https://www.google.com/search?q=https%3A%2F%2Fcodeforindia.org%2Fhackathon); [AgentFoundry Hackathon Hub](https://www.google.com/search?q=https%3A%2F%2Fkarlmehta.github.io%2Fcode-for-a-billion%2F)). For winning teams selected for track prizes and Code for India's open-source incubation pipeline, the GitHub repository is not just a code dump—it is the **primary technical artifact inspected by judges and adopted by NGOs and institutions**.

### 5.1 Mandatory GitHub & Open-Source Legal Requirements

1. **Public GitHub Repository Before November 15, 2026:**
   * All source code, agent prompts, database migrations, and configuration schemas must be pushed to a public GitHub repository prior to the **November 15, 2026** cutoff.
2. **Permissive Open-Source License (`Apache-2.0` or `MIT` Required):**
   * Per official FAQ rules (*"Do I keep my IP?"* on [codeforindia.org/hackathon](https://www.google.com/search?q=https%3A%2F%2Fcodeforindia.org%2Fhackathon)), projects must be released under the **Apache-2.0 License** or **MIT License** at the root of the repository (`LICENSE` file).
   * **Why This Matters for Winners:** Code for India requires `Apache-2.0` or `MIT` licensing so that any Indian NGO, public university placement cell, or government body (such as AICTE or state skill missions) can adopt and deploy the software without licensing friction, while **all team members retain permanent contributor attribution and copyright notice**.
3. **Release / Transfer to the Code for India GitHub Organization:**
   * Winning and incubated projects are released to the **Code for India GitHub organization** (`github.com/Code-for-India` / official hackathon submission organization) to enter CFI's open-source incubation pipeline.
   * **Winner Preparation Rule:** Keep the repository completely self-contained with zero proprietary submodules, zero hardcoded personal account URLs, and clean environment variable templating (`.env.example`) so transferring or forking the repository into the **Code for India GitHub organization** works in one click without breaking CI/CD or Vercel builds.
4. **Structured One-Click GitHub Submission Form:**
   * Step 4 of the official participation workflow (*"Submit on GitHub — One click — a structured form captures your problem statement, repo, and demo"*) requires submitting via the official GitHub Submission Hub linked on [codeforindia.org/hackathon](https://www.google.com/search?q=https%3A%2F%2Fcodeforindia.org%2Fhackathon) and [karlmehta.github.io/code-for-a-billion](https://www.google.com/search?q=https%3A%2F%2Fkarlmehta.github.io%2Fcode-for-a-billion%2F).
